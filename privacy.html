מערכת הנגריה · נחלה טובה בע"מ (רהיטי הנגר, וניסה מטבחים) · עודכן לאחרונה: 5 בנובמבר 2026

"מערכת הנגריה" היא מערכת ניהול פנימית של נחלה טובה בע"מ. היא משמשת רק את בעלי העסק ואת העובדים שלו, ואינה מוצעת לציבור.

אילו נתונים המערכת קוראת

בהרשאה של בעל החשבון, המערכת קוראת את תיבות ה-Gmail העסקיות של העסק, בהרשאת קריאה בלבד (gmail.readonly). מכל מייל נשמרים: שולח, נמען, נושא, תאריך, תוכן המייל כטקסט, רשימת הקבצים המצורפים ומצב "נקרא / לא נקרא". הקבצים המצורפים עצמם לא נשמרים. הם נמשכים מ-Gmail רק כשמשתמש מורשה מבקש להוריד אותם.

למה

כדי לשייך מיילים מלקוחות, מספקים ומאדריכליות לכרטיס המתאים במערכת, ולהתריע לצוות על פניות חדשות.

מה המערכת לא עושה

  • לא שולחת, מוחקת או משנה מיילים, ולא מסמנת אותם כנקראו.
  • לא מוכרת, משתפת או מעבירה נתונים לגורם שלישי, ולא משתמשת בהם לפרסום.
  • לא משתמשת בנתונים לאימון מודלים של בינה מלאכותית.

השימוש במידע שמתקבל מ-Google API עומד ב-Google API Services User Data Policy, כולל דרישות ה-Limited Use.

אבטחה ושמירה

הנתונים נשמרים במערכת של העסק בלבד. הגישה אליה מוגנת בסיסמה, ובאזור ההגדרות גם באימות דו-שלבי. ההרשאה ל-Google נשמרת מוצפנת. אפשר לבטל את הגישה בכל רגע, בכפתור "ניתוק" במערכת או בדף ההרשאות של חשבון Google. אחרי ביטול, המערכת מפסיקה לקרוא מיילים.

Privacy Policy (English summary)

"Nagaria System" is an internal management tool used only by Nachala Tova Ltd. and its staff. With the account owner's consent it reads the business Gmail mailboxes using read-only access (gmail.readonly). It stores sender, recipient, subject, date, message text, the list of attachments and read/unread status, in order to link emails to customers and suppliers and to alert staff. Attachments are fetched from Gmail only on request and are not stored.

The app never sends, deletes, modifies or marks emails as read. Data is not sold, shared with third parties, used for advertising, or used to train AI models. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Access can be revoked at any time via the app's "Disconnect" button or at myaccount.google.com/permissions. Contact: r5617475@gmail.com
